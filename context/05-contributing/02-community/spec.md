# Community — Spec

This document specifies public community surfaces and support expectations.
It builds on [requirements.md](./requirements.md).

## Status

Draft.

## Surfaces (LS.CONTRIB.COMM-R01)

| Surface | Where | Purpose |
| --- | --- | --- |
| Discord | invite via docs site (`DISCORD_INVITE_URL`) | community help, `#contrib` coordination, sponsor channels |
| Office hours | `lu.ma/livestore`, recordings on the community page | live Q&A with the maintainer |
| Contributor sync | `docs.livestore.dev/misc/contributor-sync/`, recordings on the community page | contributor coordination |
| Conference talks / podcasts | linked from the community page | outreach |

Scheduling, publication, and operation of contributor meetings are owned by
[01-contributor-meetings](./01-contributor-meetings/spec.md). The public
[schedule JSON](./meeting-schedule.json) retains its established URL.

## Support Model (LS.CONTRIB.COMM-R02)

Non-sponsor support is best-effort via Discord and GitHub issues (minimal
repro required, LS.CONTRIB-R06). There is no SLA. Sponsors additionally get
the published benefits owned by `06-sustainability/` (LS.SUST-R05).

## Derived Pages (LS.CONTRIB.COMM-R03)

The docs community page and FAQ's community/support statements follow this
node. The contributor-sync page derives from the contributor-meetings child.
